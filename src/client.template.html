Client-side encryption and steganography

Single-factor mode. No keyfile or hardware key is loaded. The only secret is your password. Argon2id makes brute-force expensive, not impossible — a weak password is still a weak secret. Add a keyfile or (on HTTPS) a hardware key for a second independent factor.

A keyfile is a 32-byte random secret file. Both the password and the keyfile are required to decrypt. Store it separately from the encrypted data.

or load existing

Your hardware key contributes a secret to key derivation. The key must be present to decrypt. Requires FIDO2 with the PRF extension (YubiKey 5+).
